# 島嶼慢行｜馬祖四天三夜

為 2026/8/19–8/22 基隆、南竿、大坵與北竿行程製作的單頁互動旅遊網站，包含 44 個時間節點、簡易路線圖、夜間搖櫓船、每日餐飲與馬祖必吃美食。

線上版本：[GitHub Pages](https://urash0519.github.io/matsu-3day-trip/)

## 最終行程簡介

- **8/19｜基隆夜航**：20:00 基隆廟口夜市晚餐，21:30 新臺馬輪登船，22:00 開航前往南竿。
- **8/20｜南竿西線、藍眼淚**：07:00 抵達福澳，依序走介壽獅子市場、北海坑道、大漢據點、阿珠虫弟餅、鐵堡、津沙與馬港；18:45 大眾飲食店晚餐，19:40 於北海坑道內報到，20:00 搭已預約的夜間搖櫓船。住宿沐光民宿。
- **8/21｜大坵、北竿環島**：09:00 福澳碼頭報到，銜接 09:30 大坵船班；11:40 從大坵返航、約 12:10 抵白沙，接著走阿婆魚麵、短坡山、戰爭和平紀念公園、塘後道、壁山、橋仔、芹沃與芹壁。住宿大宅三院。
- **8/22｜北竿晨遊、南竿搭機**：播音站、坂里早餐、坂里大宅、黃金地瓜餃與坂里沙灘；11:45 抵白沙港報到、預計 12:00 左右搭船，12:25 抵福澳，午餐後走八八坑道，15:15 抵達南竿機場，18:20 起飛、19:10 抵松山。

## 行程調整過程

1. 最初依三份參考行程規劃為「基隆夜航、南竿進、北竿出」，並整合重疊景點、每日餐廳、馬祖小吃與藍眼淚體驗。
2. 回程訂票後確認 8/22 僅剩 18:20 從南竿起飛，因此比較「兩晚都住南竿」及「南竿、北竿各住一晚」兩種方案。
3. 決定保留 8/21 北竿住宿後，上一版曾規劃 8/22 搭 15:20 白沙港船班回南竿，16:00 僅作備案；夥伴細排版再改為中午回南竿，增加班機緩衝。
4. 北海坑道夜間搖櫓船確認預約到 8/20 20:00 梯次，官方要求提前 20 分鐘報到。原訂 17:10 晚餐因此調整為 18:00–18:50，19:05 出發，保留約 15 分鐘的額外交通與報到緩衝。
5. 因北竿第一天下午原本只有芹壁，將芹壁保留兩小時，15:20 後增加馬祖播音站、壁山觀景台及戰爭和平紀念公園主題館；翌日上午再加入與坂里大宅步行可達的坂里沙灘，讓兩天路線更完整但不壓縮回程緩衝。
6. 依夥伴最後細排版本，網站改為四天共 44 個時間節點，並加入可依日期切換、可點節點展開介紹的非比例路線圖。核對官方旺季船班後，8/21 大坵調整為 09:30 福澳開船、11:40 返航、約 12:10 抵白沙；藍眼淚則保留已確認的 19:40 報到。大漢據點與鐵堡加入出發前確認開放狀況的提醒。

船班、海象、景點開放時間與餐廳供餐狀況仍以出發前及當日公告為準。

## 開啟方式

直接開啟 `index.html`，或在專案目錄啟動任一靜態檔案伺服器：

```powershell
python -m http.server 4173
```

瀏覽 `http://localhost:4173`。

## 功能

- 依日期篩選行程
- 44 個景點、餐廳、住宿、體驗與交通節點
- 可依日期切換、點擊節點展開介紹的簡易路線圖
- 可依主食、海鮮、點心、飲品篩選的馬祖美食清單
- 景點詳情與 Google 地圖連結
- 整張行程卡皆可點擊展開介紹，卡面直接顯示行程時間與建議停留時間
- 使用瀏覽器 `localStorage` 保存必去清單
- 手機、平板與桌面版響應式排版，手機版保留完整 ROUTE 圖示與文字說明
- 圖片來源標註與載入失敗備援
