# 島嶼慢行｜馬祖三天兩夜

為 2026/8/19–8/22 南竿、北竿行程製作的單頁互動旅遊網站，包含夜間搖櫓船、每日餐廳與馬祖必吃美食。

線上版本：[GitHub Pages](https://urash0519.github.io/matsu-3day-trip/)

## 最終行程簡介

- **8/19｜基隆夜航**：18:15 基隆廟口晚餐，20:30 前抵達西岸旅客碼頭，22:00 搭新臺馬輪前往南竿。
- **8/20｜南竿慢遊、藍眼淚**：介壽獅子市場、八八坑道與酒廠、依嬤的店、北海坑道、大漢據點、鐵堡、津沙聚落、媽祖巨神像；18:00–18:50 在大眾飲食店晚餐，19:05 從馬港出發，19:40 前於北海坑道內報到、購票及參加行前說明，20:00 搭已預約的夜間搖櫓船。住宿南竿。
- **8/21｜北竿、大坵**：早班島際船前往北竿，08:30 搭船至大坵島，接續橋仔聚落、芹沃午餐、芹壁聚落；15:20 起順遊馬祖播音站、壁山觀景台及戰爭和平紀念公園主題館，17:10 前往塘岐，17:30 在龍福山莊用餐。住宿北竿。
- **8/22｜北竿半日、南竿搭機**：08:30 坂里大宅、09:20 坂里沙灘、10:05 短坡山，11:00 阿婆魚麵、12:00 塘後道沙灘，12:50 起於塘岐採買；13:40 取行李及還車，14:30 前抵達白沙港，15:20 搭船至南竿福澳港，目標 16:10 前抵達南竿機場，搭乘 18:20 班機返台。

## 行程調整過程

1. 最初依三份參考行程規劃為「基隆夜航、南竿進、北竿出」，並整合重疊景點、每日餐廳、馬祖小吃與藍眼淚體驗。
2. 回程訂票後確認 8/22 僅剩 18:20 從南竿起飛，因此比較「兩晚都住南竿」及「南竿、北竿各住一晚」兩種方案。
3. 最終保留 8/21 北竿住宿，讓大坵、橋仔、芹壁及龍福山莊不必壓縮；8/22 改搭 15:20 白沙港船班回南竿，16:00 僅作備案，不安排 16:30 以後船班。
4. 北海坑道夜間搖櫓船確認預約到 8/20 20:00 梯次，官方要求提前 20 分鐘報到。原訂 17:10 晚餐因此調整為 18:00–18:50，19:05 出發，保留約 15 分鐘的額外交通與報到緩衝。
5. 因北竿第一天下午原本只有芹壁，將芹壁保留兩小時，15:20 後增加馬祖播音站、壁山觀景台及戰爭和平紀念公園主題館；翌日上午再加入與坂里大宅步行可達的坂里沙灘，讓兩天路線更完整但不壓縮回程緩衝。

船班、海象、景點開放時間與餐廳供餐狀況仍以出發前及當日公告為準。

## 開啟方式

直接開啟 `index.html`，或在專案目錄啟動任一靜態檔案伺服器：

```powershell
python -m http.server 4173
```

瀏覽 `http://localhost:4173`。

## 功能

- 依日期篩選行程
- 26 個景點、餐廳、體驗與回程交通停靠點
- 可依主食、海鮮、點心、飲品篩選的馬祖美食清單
- 景點詳情與 Google 地圖連結
- 整張行程卡皆可點擊展開介紹，卡面直接顯示行程時間與建議停留時間
- 使用瀏覽器 `localStorage` 保存必去清單
- 手機、平板與桌面版響應式排版，手機版保留完整 ROUTE 圖示與文字說明
- 圖片來源標註與載入失敗備援
