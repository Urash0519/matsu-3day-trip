# 島嶼慢行｜馬祖三天兩夜

為 2026/8/19–8/22 南竿、北竿行程製作的單頁互動旅遊網站，包含夜間搖櫓船、每日餐廳與馬祖必吃美食。

## 開啟方式

直接開啟 `index.html`，或在專案目錄啟動任一靜態檔案伺服器：

```powershell
python -m http.server 4173
```

瀏覽 `http://localhost:4173`。

## 功能

- 依日期篩選行程
- 22 個景點、餐廳與體驗停靠點
- 可依主食、海鮮、點心、飲品篩選的馬祖美食清單
- 景點詳情與 Google 地圖連結
- 使用瀏覽器 `localStorage` 保存必去清單
- 手機、平板與桌面版響應式排版
- 圖片來源標註與載入失敗備援
